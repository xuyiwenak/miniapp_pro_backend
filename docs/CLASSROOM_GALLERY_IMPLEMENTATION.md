# 课堂作品廊与匿名互评实现记录

日期：2026-09-14。范围：教育版学生 H5、教师网页、common 契约与课堂后端。

## 本轮行为

- 上传页并列选择自己上传、教师代传；学生本人决定向本课堂匿名展示，默认关闭。
- 教师上传去标识衍生图片。图片通过检查后可供独立评价；同图生成的 AI 文字另经检查后解锁。
- 作品列表提供分页、自主选择、我的作品及评价进度；不返回作者编号、作者意图或他人评价。
- 独立评价采集情绪 1–3 项、作品 VAD 三项、信心及选填文字。正式提交锁定，重试不重复计数。
- 提交独立评价后才返回 AI 内容。逐模块三选项全部必评；修订保留首次反馈和后续版本。
- 作者自己的意图不再重复采集 VAD，使用情绪图卡、表达充分程度、选填文字。T0/T1 保持原样。
- 教师查看独立评价人数、AI 完成人数和距离 3 人目标的缺口。Excel 新增四张独立工作表。

## 数据与边界

`GalleryWork` 保存来源哈希、私有展示图、展示图哈希、单独的 AI 版本、审核状态。
`PeerReview` 按课堂/学生/展示版本唯一，保存独立答案、模块反馈、修订历史及请求幂等记录。
接口复用参与凭证、教师课堂管理能力及课堂写锁。

- 同学获取图片通过鉴权代理，不返回 OSS 原始资源地址。
- 每次读取、提交检查当前作者展示授权和作品哈希；撤回或换图后旧资源停止新访问。
- 独立评价提交前没有 AI 正文、标签、分值、建议或分析资源地址。
- closed 拒绝展示设置、草稿、独立提交和反馈写入；只读不会补写曝光事件。
- 同图重复准备复用展示版本；生成失败可以重新上传相同图重试。撤回后重新同意需重新检查。
- 作者核心课堂完整性与匿名互评完整性分开计算。

## 验证

- 后端 TypeScript 与 ESLint 通过。
- `npm test -- --grep 'classroom|Classroom'`：55 项通过，含新画廊校验、阶段门禁、锁定、修订、
  封存拒写、无效请求不创建任务和导出隔离。
- 学生端和教师端生产构建通过；教师端已有大包提示仍存在。
- 390 × 844 CSS 手机视口下实际操作：图卡选择、VAD、独立提交、三项模块反馈、已评价状态、修订入口、
  自传/代传切换。浏览器错误日志为空。
- 本地预览使用演示数据与样例图，不接入真实课堂；模拟接口仅在单独的开发 HTML 入口引用。

## 发布及正式采集前

本轮未部署，未运行真实 OSS / DashScope / MongoDB 联调。上线时需以测试课堂验证上传、教师检查、
跨设备续评和私有图片访问；不得把本地模拟页面视为外部服务验收。

研究保留政策尚待确认：本实现撤回后停止展示，保留历史答案并在导出中标记排除，不做不可逆删除。
保留期限、封存后撤回处置应在正式采集前补入说明。选填互评文本当前不进入导出。

作品采用稳定游标分页；按较少评价数优先呈现属于需求中的推荐项，本轮未加入动态排序。
去标识使用教师上传处理后图片，本轮没有新增在线图片遮挡编辑器。

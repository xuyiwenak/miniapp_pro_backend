# 作品表达意图与 AI 反馈评价：第一批实现说明

日期：2026-09-13。依据外部 PRD v1.3；本文件记录本地实现与验收边界，不代表已经发布。

## 实现范围

保留现有课堂、参与记录、作品模型和五步导航，在最后一步内加入表达意图、AI 回响、反馈评价。
没有新增独立角色体系、后台应用或第二条个性化 AI 生成链路。

- 学生完成 T1 后保存或提交意图；缺作品时先保存参与归属，作品到账后绑定作品哈希。
- 入口使用一个课堂参与说明勾选，说明涵盖 AI 分析及文字研究使用；同一操作按 v4 分别记录两类同意事件。
  后续页面不再重复选择；既有未授权记录不会被自动改写。
- AI 只接收作品图片；画面内文字由多模态模型识别并参与融合分析，不输入学生意图或 T0/T1。
- 学生报告出口校验参与归属、AI 授权、T1、意图提交、作品哈希和分析快照。
- 整体评价包含三个必答 1–7 题，模块回应为可选分类，另有一条可选总评。未答、未展示、无法判断分别处理。
- 首次提交与后续修订分别保留；报告曝光后的意图修订标记为非独立初始意图。
- 报告返回与页面展示分别留事件时间；页面展示确认不等于证明完整阅读。
- 同设备使用原参与令牌；个人返回链接使用独立随机凭据，服务端只存哈希。链接凭据放在 URL fragment，
  恢复后从地址栏移除。重新生成会使旧返回链接失效，原参与令牌仍有效。
- closed 后允许未完成者查看自己的既有记录，但不再保存草稿、评价、授权、展示事件或 AI 迟到结果。
- 教师只能代传图片；协作者默认可看汇总，明细、敏感导出和代传按能力授权。
  课堂所有者继续负责课堂配置、开放、关闭与协作权限分配，权限修改限草稿阶段。
- 导出扩展现有工作簿，增加意图/评价、模块回应、授权事件、AI 运行记录。
  常规导出排除意图文本、总评、自由文本代传原因与 AI 证据原文；敏感文本导出同时要求教师权限与学生授权。
  统计使用首次提交记录，草稿不纳入评价分布，不生成综合总分。

本批不开放合法跳过意图，沿用 PRD 的默认禁止设置。匿名互评属于第二批。
旧数据迁移、独立自动封存任务、本地草稿自动重试同步均未加入。

## 存储与运维边界

课堂图片使用 OSS 私有对象及短时签名访问地址，上传失败直接返回失败，不回退公开本地文件地址。
公共上传调用默认行为保持原样。上线前须验证实际 bucket 策略不能匿名读取新课堂对象，且模型服务能使用签名地址。

为防止封存与在途写入交叉，课堂级数据库锁采用不可自动过期的随机令牌；常规请求结束会释放。
获取锁最多等待约四秒，失败返回 `CLASSROOM_BUSY`，由用户手动重试。

进程异常退出可能遗留 `classroom.writeLock`。运维恢复须先停止或确认所有可能持有该锁的旧进程已退出，
再核对该课堂实际锁值，以 `classId + 原锁值` 为条件执行 `$unset: { writeLock: 1 }`，关闭自动更新时间，
记录独立运维审计。不得按时间自动清除仍可能活跃的锁，也不得无条件批量清除。
这项操作没有开放给普通教师，且不是独立后台自动封存任务。

AI 在内存中异步运行，进程退出不会自动重放任务；未成功落库的运行保留未完成状态，封存时记为
`closed_incomplete`。不能把未落库结果补入已封存课堂。持续锁竞争也可能导致异步结果未提交，需观察
`education.artwork.result.not_committed` 日志；恢复后只能在可写课堂中按现有失败处理流程处理。

个人返回入口生成、封存只读；无页面运行异常。浏览器测试不等价于真实服务端联调。

5. 协作者汇总/明细/敏感导出权限，学生撤回文本授权后的实际导出内容。
6. 对导出中的首次版本、缺失原因、报告版本和实际页面逐条核对。

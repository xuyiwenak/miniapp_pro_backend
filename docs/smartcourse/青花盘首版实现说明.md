# 青花盘首版本地实现

2026-10-18。尚未发布线上；旧课程保持原流程，新建课程可选 `qinghua-plate-v1`。

## 已实现

- 四步课堂：原稿上传与圆形取景、连续排列、单双圈盘面、成品保存。
- 原稿归一化为去 EXIF 的 PNG，保留透明度，不覆盖原作；拖动、双指/滑杆缩放、旋转、完整放入与铺满。
- 去白底与青花配色独立；统一三档配色。
- 一组项目原创矢量预设：青叶、小花、双叶、菱形、连续水波。单元保持比例；水波由周期函数闭合成环。
- 8/12/16 单元，同向/镜像/旋转交替，朝外/朝内/切向；固定环带与留白；双圈参数独立保留。
- 可选署名方章：2 字补“之印”，3 字补“印”，4 字直接使用；右列先读。拒绝非汉字及字体缺字。
- 2048 PNG 由服务端生成。预览与导出使用同一渲染器，字体转路径，避免浏览器或服务器字体差异。
- 显式保存、刷新恢复、乐观版本冲突校验、按版本幂等导出、历史导出关联当时的原稿和参数。
- 学生数据隔离；教师按学生汇总；关闭课程后禁止修改，允许查看保存的设计和成品。

## 实现边界

预览通过服务端生成并串行合并过时请求，网络延迟影响更新速度；尚未进行全班并发压测，不宣称达到 200ms。
边饰单独上传当前使用完整矩形并自动去除透明空边，尚无独立矩形裁剪工具。
教师端显示原稿、参数与成品，暂未单独展示每个中间处理图。
矢量预设随应用版本内置，不需要在 OSS 创建空目录；用户素材与成品均在配置的 smart/user_upload/works 前缀下。
没有新增 AI 材质生成、自由题字、后台自动封存或本地草稿自动重试。
手机尺寸验证使用 Chrome 模拟视口，尚未在 iOS/Android 微信真机验证。

## API 与持久化

学生端（均要求学生会话及课程归属）：
- `GET /smartcourse-api/courses/:courseId/design` 读取保存版本和素材签名。
- `POST .../design/assets` 上传图片，服务端解码校验。
- `PUT .../design` `{revision,state}` 显式保存；冲突 409。
- `POST .../design/preview` 预览未保存参数；仅开放课程。
- `GET .../design/preview` 只预览服务端已保存参数，关课后仍可读。
- `POST .../design/export` `{revision}` 生成/返回该版本成品。

Mongo：SmartPatternAsset 与 SmartPatternDesign；课程+参与者唯一设计索引。
OSS：`smart/user_upload/works/{courseId}/{participantId}/pattern/originals/{assetId}.png` 与 `pattern/exports/{revision}.png`。
设计 JSON 经严格 Zod 校验，导出记录保存渲染版本和参数快照。服务端不接受任意 URL 或 OSS key。

## 素材许可

预设几何/花叶路径为本项目原创教学素材，不从参考瓷盘照片提取。
印章字形使用 LXGW WenKai 1.522，SIL Open Font License 1.1；随发布包含 OFL.txt。
来源：https://github.com/lxgw/LxgwWenKai/tree/v1.522
字体通过 opentype.js 生成字形路径；完整字体仅在后端，不向手机加载 24 MB 字体文件。

## 陶瓷实物效果图（2026-10-18）

第四步新增可选“生成陶瓷效果图”。默认 qwen-image-3.0，1024×1024，每次一张，复用百炼 API Key。
准确设计仍为独立 2048 PNG；AI 图标注“AI 效果参考”，私有 OSS 路径为
`smart/user_upload/works/{courseId}/{participantId}/pattern/ceramic/{revision}.png`。

- `POST /courses/:courseId/design/ceramic` 接收 `{ revision }`，必须是本人当前已导出的版本且课程开放。
- `GET /courses/:courseId/design/ceramic` 返回本人历史任务；`GET .../ceramic/:revision` 查询并保存已提交任务。
- 数据库按课程、参与者和设计版本唯一索引；并发锁及提交限流防止重复生成。
- 百炼异步任务编号持久化，服务端定时查询并转存结果，重启后继续查询已有任务，不自动提交新任务。
- 网络错误导致提交状态不明时暂停重试，避免重复收费；明确失败才开放手动重试。
- OSS 下载/保存失败保留原任务，重试保存不重新生图。超过供应商查询期限的任务标记状态不明，需核查。
- 教师可查看准确盘面及 AI 效果图；学生可以查看、打开历史 AI 图。关闭课程后仅继续保存已提交结果。

# 课堂作品报告 v2（2026-09-14）

## 本次核查

对「v4匿名」已保存分析进行只读核查：模型 qwen3.8-flash，提示词 education-artwork-affect-prompt-v1。
visual 与 fused 两个通道的 social_aversion 均为 assessable=false、score=null，理由为「画面证据不足」。
因此不是接口漏传。v1 示例单独把这一维写为 null，可能构成示例偏置，但不能证明此次缺失完全由此造成。
教师雷达原来只在所有维度都有分数时绘制数据；一个维度缺失会让整条数据轮廓消失。

原报告还存在：整体解读只笼统说文字强化主题、模块篇幅短且缺少具体关系、文字被单列显示、署名未被识别为潜在身份信息。
这次没有改写已有课堂的报告、分数、首次评价或曝光快照，也没有重新调用线上模型覆盖旧结果。

使用 v2 提示词对同一图片做了一次非入库抽样，模型返回 `NOT_ARTWORK`，理由为图片是数字设计的电影海报，
不属于当前规则限定的实体手工作品。该结果没有写入课堂或覆盖旧报告，因此 v4 不能用于验证 v2 分层正文质量；
后续应另选一件符合课堂作品边界的图片做正式输出抽样。

## 已实现

- 新生成报告使用 education-artwork-affect-prompt-v2 和 artwork-report-v2。
- 保留视觉、文字线索、图文关系与融合结果的内部审计；学生看到融合后的整体解读，不单列画内文字模块。
- 整体解读分三段：可见印象、可靠图文关系、综合理解及另一种有依据的读法。
- 色彩分位置、关系、效果；线条与构图说明具体特征及视觉作用；建议提供两个有作品依据的可选尝试。
- 标题、日期、署名不自动当作情绪依据；文字不清时不猜读，身份信息不转录。
- 去除预设数值示例，社交抵触与其他维度一样独立取证。低强度与无法判断分开，缺失必须具体说明。
- 学生八维雷达展示融合得分，可选择维度查看依据；缺失处不连线、不补零，其余有效点继续绘制。
- 按已确认的产品方案，新学生报告取消 VAD 展示及评价；VAD 保留在教师查看与研究审计中。
- 教师 VAD 展示为只读图形，保留 0–100 量尺及端点说明，不触发第二次课后测评。
- 教师雷达也支持部分缺失；教师报告保留段落换行。
- 新增 affectDimensions 评价模块，沿用三选项反应编码；仅对本份快照实际展示的模块要求评价。
- 新学生报告为五个模块：整体表达、色彩、线条与构图、八维情绪表达、创作尝试。
- 学生报告接口会过滤历史快照中的 VAD 模块，避免页面不展示却仍要求提交 VAD 评价。
- 旧画内文字评价保留；不强制旧报告补评新模块。
- 匿名互评提交后只锁定评价输入，查看图表依据仍可操作。

## 生成校验与边界

新生成文本校验段落数、长度和完全相同的重复段落，结构不合格最多重新请求一次；再次不合格保留失败。
校验不能证明语义正确，也不能保证社交抵触必然有分数。仍无可靠依据时应保留 null。
默认输出预算与配置示例由 4096 调为 8192；部署时应核对真实配置中是否另有显式覆盖值。
修复请求的结构错误码记录到采样参数；未新增后台自动任务或课堂封存后数据写入。

## 验证

覆盖报告快照图文合并、八维缺失保留、文本结构校验、署名脱敏、旧报告不强制新模块、新报告新模块必评。
本地浏览器完成模拟报告的就地评价、缺失依据查看和提交锁定检查；最终学生报告调整为五个模块。
